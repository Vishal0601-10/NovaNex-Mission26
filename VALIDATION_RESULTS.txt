WINDOWS STATIC FILE FIX (2026-10-12)
====================================

Root cause: static-file path containment used a hard-coded forward-slash prefix check. Valid Windows paths use backslashes, so app.js/CSS/ES modules were rejected.
Fix: containment now uses node:path relative() + isAbsolute(), which is platform-aware.
